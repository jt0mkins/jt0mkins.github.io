# Joella Tomkins: Embedded Systems Portfolio

**🌐 Live site: [jt0mkins.github.io](https://jt0mkins.github.io/)**

Custom microcontroller hardware, firmware, PCB design and RF.

## Embedded projects

- **RF Rocket Downlink**: honours project. A custom STM32H5 and SX1262 LoRa telemetry board at 915 MHz, PCB J-pole antenna and dynamic link budget for the UC Aerospace hybrid rocket
- **Landing Bay Camera System**: a custom STM32 board bridging a spaceplane flight computer's GPIO to a 4K camera's UART (Dawn Aerospace)
- **1kW Electric Go Kart**: Arduino battery and speed telemetry with interrupt-driven IR sensing and Bluetooth serial displays (1st place in three EVolocity national events)
- **Solar-Powered RC Car Program**: an outreach program with a custom PCB and embedded firmware ([PCBs](https://github.com/jt0mkins/YWIM_Solar_Car_PCBs), [firmware](https://github.com/jt0mkins/YWIM_Solar_Car_Firmware))

## Other projects

- **Weightlifting Form Analysis**: Python and OpenCV pose tracking
- **Café Map**: [interactive map](https://jt0mkins.github.io/cafe_map/) of NZ café reviews

Built with plain HTML and CSS and hosted on GitHub Pages.
