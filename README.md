# Joella Tomkins: Projects Portfolio

**🌐 Live site: [jt0mkins.github.io](https://jt0mkins.github.io/)**

A portfolio of my engineering projects:

- **RF Rocket Downlink**: 915 MHz LoRa telemetry system and dynamic link budget for the UC Aerospace hybrid rocket
- **Landing Bay Camera System**: STM32 PCB, enclosure and firmware for the Dawn Aerospace Mk-II B spaceplane
- **Young Wāhine in STEM**: solar-powered RC car outreach program for high school students
- **1kW Electric Go Kart**: Arduino telemetry and 3D printed parts for the EVolocity national competition
- **Weightlifting Form Analysis**: Python and OpenCV pose tracking for lifting technique
- **Café Map**: [interactive map](https://jt0mkins.github.io/cafe_map/) of NZ café reviews

Built with plain HTML and CSS and hosted on GitHub Pages.
